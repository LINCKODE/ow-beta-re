## Details

### `0x01` SceneTransform (scene node / render transform)
- **Change detection + dirty list** [G, 2026-09-29, read-only research]: the scene
  transform setter (`FUN_7ff6509e45c0` → `FUN_7ff6509e3320`) compares the new position / rotation with the stored
  ones (epsilon) and returns early if unchanged; on a change it appends the node once per frame to a per-scene dirty
  list (atomic, thread-safe). The scene update (`FUN_7ff6509d4310`) swaps the two list buffers, bumps an epoch (so
  nodes can re-enqueue next frame), processes parents before children (on worker threads from 16 dirty nodes up),
  steps the prop physics (`dmWorld_Step`) before propagating transforms, then submits to the renderer.
Per-entity scene node: position/rotation/scale and render flags; the base that almost every other component depends on. Inline-capable (544 B) so map geometry entities carry it in-place.
- added by: dependency of most components (0x03,0x06,0x0c,0x16,0x1d,0x41,0x45,...) and map inline spawns
- 96 entity definitions in the game EA
- server: Server needs transforms but not this render node; position replicates via movement state (0x12).
- fields: `0x50` scaling Vec4 (Prometheus Component_1_SceneRendering); `0x60` position Vec4; `0x1a8` attached scene-proxy interface ptr (set by 0x06/0x0c/0x45 OnCreate); `0x1b8` render/scene flag qword
- evidence: Prometheus Component_1_SceneRendering; OnCreate of 0x06/0x0c/0x45 fetch comp 0x01 via mask bit 1 and write +0x1a8/+0x1b8; creator slot1 FUN_7ff6509e6380 -> ctor FUN_7ff6509e00c0.
